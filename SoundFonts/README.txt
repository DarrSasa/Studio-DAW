SoundFonts folder
=================

Copia aici un SoundFont General MIDI (.sf2). Recomandarea free este FluidR3_GM de Frank Wen:
https://member.keymusician.com/Member/FluidR3_GM/index.html

Pagina descarcă arhiva originală și include fișierele de copyright/licență. FluidR3 este mare (~124 MB comprimat/variază pe mirror). Păstrează toate fișierele LICENSE/COPYRIGHT/README din arhivă.

Încărcare în aplicație: Setări (⚙) > Open SoundFont file > selectează fișierul din acest folder. Browserul nu permite aplicației să citească automat conținutul unui folder local; alegerea fișierului este necesară. SF2-ul rămâne local, nu este uploadat către un server. Încărcarea durează și folosește RAM; după reîncărcarea paginii poate fi necesară selectarea din nou.
